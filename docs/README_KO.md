**HiLighter**는 하이라이트 노트 관리에 특화된 Obsidian 플러그인입니다. 하이라이트한 내용을 관리하기 쉬운 노트 카드로 변환하고, 다양한 색상 주석, AI 분석, 스마트 검색을 지원하여 노트 정리를 더욱 효율적으로 만들어 줍니다.

![screenshot1](screenshots/screenshot1.png)

## ✨ 주요 기능

### 🎨 하이라이트 노트 카드 관리
*   **사이드바 관리**: 현재 문서 또는 볼트 전체의 `<mark>` 하이라이트를 모아 보여주며, 카드를 클릭하면 원문으로 즉시 이동합니다.
*   **다차원 필터**:
    *   **색상 필터**: 노란색, 분홍색, 파란색, 초록색 네 가지 하이라이트 색상으로 빠르게 분류합니다.
    *   **키워드 검색**: 상단 검색창에서 노트 내용을 실시간으로 필터링합니다.
*   **AI 기능**:
    *   **AI 번역 (Languages)**: 하이라이트한 문장을 한 번의 클릭으로 정확하게 번역합니다.
    *   **AI 리서치 (Microscope)**: 여러 연구 프롬프트 템플릿(철학적 분석, 간결한 요약, 비판적 분석)이 내장되어 있으며, **사용자 지정 연구 프롬프트**도 지원합니다 — 자유롭게 추가, 편집, 전환할 수 있어 다양한 깊이 읽기 시나리오에 대응합니다.
*   **유연한 상호작용**:
    *   **빠른 편집**: 연필 아이콘을 클릭하면 카드에서 바로 노트를 편집할 수 있으며, 높이가 자동으로 조절됩니다.
    *   **태그 시스템**: 사용자 지정 태그를 지원하고, 스마트 추천 알고리즘이 내장되어 있습니다.
    *   **카드 컬렉션**: 한 번의 클릭으로 전체 화면 "카드 스튜디오" 모드로 전환하여 영감을 체계적으로 관리합니다.
*   **노트 카드 관리**:
    *   **원문 찾기**: 카드를 클릭하면 원본 노트의 하이라이트 위치로 즉시 이동하여 맥락을 빠르게 복원합니다.
    *   **분류 태그**: 각 카드에 태그를 추가해 체계적으로 정리할 수 있으며, 태그 일괄 작업도 지원합니다.
    *   **일괄 삭제**: 일괄 모드에서 여러 카드를 선택한 뒤 한 번의 클릭으로 삭제하여 효율적으로 정리합니다.

![screenshot2](screenshots/card-studio.png)

### 📄 PDF 주석 (2.5 신규)
*   **PDF 내 하이라이트**: 어떤 PDF에서든 텍스트를 선택하고 색상을 고르면 — 페이지에 반투명 형광펜 표시가 나타나고 노트 카드가 즉시 생성됩니다. 메모, 태그, 플래시카드 복습, 마인드맵이 Markdown 하이라이트와 완전히 동일하게 작동합니다.
*   **표시 영구 저장**: 모든 하이라이트는 페이지 기하 구조에 고정되므로, 페이지 넘김, 파일을 닫았다 다시 열기, 확대/축소, 기기 간 볼트 동기화 후에도 위치가 유지됩니다.
*   **카드와 양방향 동기화**: 카드를 삭제하면 PDF 표시도 즉시 사라지고, 카드 색상을 바꾸면 표시도 즉시 업데이트됩니다.
*   **정확한 문장으로 이동**: 카드를 클릭하면 PDF에서 하이라이트된 문장으로 바로 스크롤되며, 잠깐 깜빡임으로 위치를 알려줍니다.

![pdf](screenshots/pdf-highlight.png)

### 🧠 마인드맵 (2.4 신규)
*   **원클릭 생성**: 어떤 파일의 모든 하이라이트든 마인드맵으로 가져올 수 있습니다 — 문서 제목, 하이라이트 색상, 태그 또는 나열 순서로 그룹화됩니다.
*   **Xmind 스타일 편집**: 토픽을 드래그해 계층이나 순서를 변경하고, Tab/Enter/Delete 단축키, 더블클릭 인라인 편집, 브랜치 접기/펼치기, 실행 취소/다시 실행, 임의의 두 토픽 사이 연관선을 지원합니다.
*   **9가지 구조**: 밸런스 마인드맵, 로직 다이어그램(오른쪽/왼쪽), 조직도, 가로/세로 타임라인, 피시본, 카탈로그 조직도 — 언제든 전환 가능합니다.
*   **6가지 스타일 테마 × 8가지 색상 팔레트**: 선 모양과 굵기(곡선, 직선, 무지개 브랜치 선)와 풀 컬러 스킴(배경, 노드 채우기/테두리는 계층별로 연해지는 것은 물론, 카드 색상을 살린 컬러풀한 옵션도 포함)을 조합합니다.
*   **요약과 노트**: 토픽에 요약 노드를 넣거나, 어떤 토픽에든 메모를 붙이고, 원본 하이라이트로 바로 돌아갈 수 있습니다.
*   **가져오기/내보내기**: `.xmind` 파일을 직접 열 수 있으며, PNG, `.xmind`(Xmind에서 다시 열기 가능), Markdown 아웃라인, Obsidian `.canvas` 보드로 내보낼 수 있습니다.

![mindmap](screenshots/mindmap.png)

### ⚡ 플래시카드 복습 (FSRS)
*   **간격 반복**: 내장된 FSRS 스케줄링이 하이라이트 카드를 플래시카드로 바꾸고, 마감 대기열과 카드별 복습 상태를 관리합니다.
*   **집중 복습 세션**: Space 키로 카드를 뒤집고, 회상도를 1–4(again/hard/good/easy)로 평가하며, 건너뛰기나 보관도 가능 — 모두 키보드로 조작합니다.
*   **복습 인사이트**: 스튜디오 툴바에 마감/신규 카드 수를 표시하고, 통계 대시보드에서 복습 데이터를 확인할 수 있습니다.

## 🚀 빠른 시작

### 설치
1. **수동 설치 (권장):**
    *   최신 버전의 세 가지 주요 파일(`main.js`, `manifest.json`, `styles.css`)을 받습니다.
    *   볼트 폴더의 `.obsidian/plugins/hilighter/`에 넣습니다.
    *   설정 > 서드파티 플러그인에서 플러그인을 활성화합니다.
2. **커뮤니티 플러그인:** Obsidian의 커뮤니티 플러그인 브라우저에서 `HiLighter`를 검색하여 바로 설치할 수 있습니다.

### 기본 설정
1.  **AI LLM API (중요)**: AI 번역과 AI 리서치 기능을 사용하려면 플러그인 설정에서 AI LLM API를 구성해야 합니다. DeepSeek, Google Gemini, Volcano Engine (Ark) 등 주요 공급자를 지원합니다.
2.  **리본 아이콘**: 설정에서 사이드바 하이라이트 노트 아이콘 표시 여부를 제어할 수 있습니다.

## 🔄 데이터 동기화

HiLighter는 하이라이트를 기기별 IndexedDB에 저장하지만, 볼트 내 동기화 파일(기본값 `.hilighter/sync-data.json`)을 통해 여러 기기 간에 동기화할 수 있습니다. 설정에서 **동기화**를 켜고 **iCloud** 또는 **Obsidian Sync**로 해당 파일을 동기화하세요.

- **자동 가져오기**: 플러그인이 동기화 파일을 감시하고 다른 기기의 변경 사항을 자동으로 병합합니다(약 30초 폴링 + 창 포커스 시).
- **자동 내보내기**: 로컬 변경 사항은 (약 20초 디바운스로) 다시 내보내지며, 내보내기 전에 원격 파일을 먼저 병합하므로 다른 기기의 데이터를 덮어쓰지 않습니다.
- **삭제 전파**: 경량 툼스톤(30일 후 정리)으로 삭제를 전파합니다.
- **추가/수정만**: 동기화는 행을 병합할 뿐, 명시적으로 툼스톤 처리되지 않은 행을 삭제하지 않으며, Obsidian Sync의 `*-conflicted-*` 사본은 읽지 않습니다.

**볼트로 내보내기** / **볼트에서 가져오기** 명령으로 수동 동기화도 가능합니다.

### 딥 링크

`obsidian://hilighter?op=...`이 지원하는 동작:

| op | 동작 |
|---|---|
| `sync-import` | 동기화 파일에서 가져오기 |
| `sync-export` | 동기화 파일로 내보내기 |
| `sync` | 가져온 후 내보내기 |
| `open-studio` | 카드 스튜디오 열기 |
| `open-view` | 하이라이트 사이드바 열기(`&side=main`을 추가하면 메인 영역) |

iOS 단축어 및 다른 앱에서 유용합니다. `vault=` 파라미터가 없으면 마지막으로 활성화된 볼트가 대상이 됩니다.

## 변경 로그

### v2.5.2 (2026-10-26)
- **EPUB 리더 툴바**: 목차 드롭다운(장 클릭 시 이동), 페이지 이동(자동 생성된 페이지 번호를 슬라이더와 입력으로 지정, 책별 캐싱), "마지막 읽은 위치로 돌아가기" 버튼을 추가했습니다. 목차/페이지/카드 점프는 저장된 읽기 위치를 덮어쓰지 않아 언제든 실제로 읽던 곳으로 돌아갈 수 있습니다.
- **카드 정렬**: 현재 EPUB의 하이라이트 카드가 생성 순서가 아닌 책의 읽기 순서(CFI 위치)로 정렬됩니다. 스튜디오의 원문 순서 정렬도 같은 비교기를 사용합니다.
- **EPUB 읽기 및 하이라이트(수정)**: 볼트의 EPUB 파일이 HiLighter 리더에서 정상적으로 열립니다. 이전에는 뷰가 FileView로 등록되지 않아 파일을 전달받지 못해 계속 비어 있었습니다. 텍스트를 선택해 4색 하이라이트를 만들 수 있고, 카드를 클릭하면 원래 문장으로 점프해 깜빡이며 위치를 알려주며, 카드 삭제/색 변경은 즉시 책 페이지에 반영됩니다. 손상된 책은 읽기 쉬운 오류 메시지와 재시도 버튼을 표시합니다.

### v2.5.1 (2026-10-25)
- **AI 모델 설정**: 프리셋이 이제 폼 전체를 미리 채웁니다(API 키만 입력하면 됨). "모델 목록 가져오기" 버튼으로 키로 실제 사용 가능한 모델 ID를 가져오고, 흔한 제품명(예: `deepseek-v3`)은 실제 API 모델 ID로 자동 교정됩니다. 400/404 오류 시 키로 이용 가능한 모델 목록이 오류 메시지에 표시됩니다.
- **Kimi 수정**: 새 Kimi 키는 `kimi-*` 모델만 제공하며(프리셋 기본값이 `kimi-latest`로 변경), k2.6+는 temperature 1만 허용합니다 — 이제 편집기에서 모델별로 temperature를 설정할 수 있습니다.
- **AI 설명**: 텍스트 선택 툴바에 "AI 설명" 버튼이 추가되어 짧은 주석을 노트 입력란에 바로 작성합니다. 전문 AI 분석 패널은 제거되었습니다.
- **수정**: 프리셋 선택기가 스크롤 가능해졌고, 설정 페이지는 편집 후에도 스크롤 위치를 유지합니다.

### v2.5.0 (2026-10-25)
- **PDF 하이라이트**: 어떤 PDF에서든 텍스트를 선택하고 색상을 고르면 페이지에 반투명 표시가 나타나고 노트 카드가 생성됩니다. 표시는 페이지 상대 선택 기하 구조에 고정되므로 페이지 넘김, 다시 열기, 확대/축소, 볼트 동기화 후에도 위치가 유지됩니다.
- **정확한 문장으로 이동**: PDF 카드를 클릭하면 하이라이트된 문장으로 스크롤하고 약 1.2초간 깜빡입니다(이전에는 페이지 단위만 가능).
- **양방향 동기화**: 카드를 삭제하면 PDF 표시가 즉시 사라지고, 카드 색을 바꾸면 표시가 즉시 업데이트됩니다.
- **수정**: PDF 하이라이트 캡처의 오래된 크래시(페이지 앵커가 저장되지 않던 문제), 오버레이 다시 그리기 피드백 루프, 사용자 지정 하이라이트 색이 사이드바 카드 줄무늬에 적용되지 않던 문제를 고쳤습니다.

### v2.4.1 (2026-10-24)
- **플러그인 디렉터리 수정**: manifest 이름을 ASCII 전용 "HiLighter"로 되돌렸습니다(커뮤니티 디렉터리는 비 ASCII 이름을 거부하여 항목이 숨겨졌었습니다). 이중 언어 설명은 변경 없습니다.
