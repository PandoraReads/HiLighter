# 卡片方法与知识链接

高亮后立即得到摘录卡。用户可以稍后给卡片命名、选择笔记方法、填写结构化内容，或者从摘录新建一张独立想法卡。原文和定位信息始终保留。

## 方法依据与界面呈现

| 卡片方法 | 字段与呈现 | 依据 |
| --- | --- | --- |
| 摘录 | 保留原文和自由注解，不要求当场分类 | 快速采集的默认入口 |
| 康奈尔笔记 | 左侧提示问题、右侧笔记，底部总结及延伸 | [康奈尔大学学习策略中心](https://lsc.cornell.edu/notes.html)介绍的提示栏、笔记栏、总结栏；延伸字段为产品补充 |
| 一页纸综合 | 核心结论置顶，依据、例子、适用场景并列，应用置底 | [澳大利亚国立大学的笔记指导](https://www.anu.edu.au/students/academic-skills/study-skills/note-taking/note-taking-system)建议将主题整理为一页的主摘要；五个字段是 HiLighter 对综合过程的设计，并非该来源规定的固定模板 |
| 卢曼想法卡 | 独立想法突出显示，附推理、反例或区别、可延伸之处 | [比勒费尔德大学卢曼档案](https://niklas-luhmann-archiv.de/nachlass/zettelkasten)展示了文献笔记、想法的延伸及卡片间的引用；字段是产品设计，并非卢曼规定的分类 |

这些名称代表组织笔记的方法，不代表内容只能是概念、问题或行动。同一方法卡可以同时记录多个内容要素。卡片集和右侧栏直接显示各方法的版式。

## 操作路径

1. 高亮时先生成摘录卡。侧栏翻译按钮右侧的“整理卡片”打开详情。
2. 可选填简短标题；无标题时卡片关联优先显示原文开头。选择方法后填写字段，自由注解仍保留。
3. “从此摘录新建想法卡”位于模板选择之前。它保留原摘录，另建一张可命名、可关联的想法卡，并记录来源关系。
4. 关联区可搜索卡片，也会按同源文件和共同标签推荐卡片。关系下拉菜单包含相关、支持、反驳或对照、延伸、应用于、举例说明、来源于；末项允许自定义。
5. 卡片集可按方法分组和筛选。Markdown 导出包含方法、卡片 ID、来源卡片 ID 与关系。

## 旧数据兼容

旧卡片无方法时按摘录展示。此前的概念、观点、问题、行动模板分别映射到一页纸综合、卢曼想法卡、康奈尔笔记、一页纸综合，已填写字段在编辑和同步时保留。新字段写在原卡片记录中；IndexedDB 索引未变。反向引用由有向关系计算。
