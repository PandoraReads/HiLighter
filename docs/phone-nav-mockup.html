手机顶栏设计稿

五个入口（近期、书架、统计、卡片集、设置）并成一排、等距排开的纯文字导航，是下面方案 A 与 A2；方案 B 是保留气泡的紧凑版备选。手机画面里的按钮可以点按切换选中态，右上角可切换深浅色预览。

演示主题

关于「仍然是分行」

我核对过 PandoraBooks 部署目录：styles.css 与 main.js 都和源码一致，手机顶栏规则从 v2.8.5 起就是 flex-wrap: nowrap 的单行布局。手机上仍看到两行，最可能是 iCloud 还没把新版样式同步到手机（旧版顶栏确实是会换行的 flex-wrap: wrap）。方案 A / A2 / B 都不依赖这条修复，纯文字五项总宽度远小于屏幕，结构上不会再换行。

实施要点

  • 方案 A / A2：view.ts 的 buildHeader 加手机分支，三个页签与卡片集、设置并排渲染成同一排文字按钮（手机上省去图标，卡片集与设置显示文字标签）；styles.css 重写 .is-phone 顶栏规则（space-evenly、44px 行高、无背景无边框）。A2 只是多一条选中下划线。
  • 方案 B：只改 styles.css：.is-phone 下顶栏 40px、气泡内边距 4px 9px、图标按钮 30px，其余不动。
  • 三案共同：品牌文字在手机上继续隐藏；设置的弹出菜单（主题 + 深浅色）不变；思维导图页签在手机上继续隐藏。
  • 验收：实施后重建 main.js，连同 styles.css 拷贝到 PandoraBooks，手机端确认 iCloud 同步完成（文件大小与电脑端一致）后再看效果。

怎么定

看完设计稿回复 A、A2 或 B 即可；想调细节（字号、字重、间距、下划线长短、行高再收一点）直接说，我改完稿再确认，通过后才动代码。
