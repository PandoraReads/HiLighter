# 卡片管理与闪卡复习改版提案

状态：已按 Rae 确认的方向实施。[交互式 HTML 样本](./card-review-interface-sample.html)用于视觉参考，其中卡片数据和复习间隔仍为演示内容。

## 现状与目标

当前管理页的宫格卡片使用固定方形、大段摘录和接近白色的背景。`styles.css` 还隐藏了卡片中的笔记预览，因此管理页难以快速区分“摘录”和“自己的笔记”。列表模式只显示摘录与来源。闪卡复习已接入 FSRS、到期/新卡入口及“重来/困难/良好/简单”四级评分，但界面是左右两页的杂志排版，翻面前右页占位仍可见，记忆测试的正反面不够明确。学习中的卡片会立即排回队尾，可能在到期时间之前重复出现。

目标：让管理页先帮助用户找回学习语境，再让复习页围绕“先回忆，后看答案，最后评分”展开。沿用现有 `HighlightNote` 与 FSRS 状态，首版不改数据库 schema。

## 方案 A：管理页卡片

采用一张信息层次明确的“学习卡”，宽度随现有列数设置变化，高度由内容决定，避免所有摘录被方形裁断。

```text
┌────────────────────────────────────┐
│ ● 蓝色 · 词汇       学习中 / 明天到期 │
│                                    │
│  take something for granted        │  ← 摘录，最多 3 行
│  想当然地认为……                     │  ← 我的笔记，最多 3 行
│                                    │
│  #阅读  #表达         来源 · 10/22   │
└────────────────────────────────────┘
```

- 摘录是主标题，笔记为次级内容；有图片时显示一张小缩略图和“另有 N 张图片”。无笔记时显示“添加笔记”，不要留大片空白。
- 顶部用窄色条或圆点承接用户的高亮颜色，卡面使用 Obsidian 主题背景变量，浅色和深色主题都保持可读。颜色只作分类线索，不铺满整张卡。
- 底部保留来源、日期和前两个标签；右上角保留固定/批量选择。点击卡片仍打开现有详情；拖到分组仍执行现有分类操作。
- 复习状态只在有 FSRS 记录时出现“学习中/到期/已安排”，新卡显示“未复习”。列表模式同步增加一行精简笔记预览。
- 首版按现有 `cardDensity` 做舒适/紧凑两种间距，尊重现有列数和主题设置。截断内容在详情弹窗中完整呈现。

### 现有管理功能的保留范围

复查 `src/studio/toolbar.ts` 与 `src/studio/studio-view.ts` 后，正式改版保留搜索；按文件、标签、颜色、日期分组；按时间倒序、时间正序、名称 A–Z、Z–A 排序；当前分组项的多选筛选；全部折叠/展开；宫格/列表切换；到期复习、新卡学习和复习设置入口；批量操作；统计入口。分组标题、数量、拖拽归类、固定、详情，以及现有状态过滤继续可用。

统计入口现在在卡片管理页右上角可见，沿用原统计面板和数据，不新建统计数据。统计页继续展示笔记总量、连续记录、本周记录、FSRS 到期与已复习、热力图、高亮颜色、标签和文件分布。样本右上角的主题下拉和明暗按钮仅用于比较设计；正式产品继续通过插件已有外观设置选择主题。

### 全主题适配

现有主题共九种：Editorial、Native、Paper、Ocean、Forest、Galaxy、Cyber、Sunset、Rose。样本为每种都提供浅色/深色预览。实现已为主背景、表面、卡面、文字和边框定义主题语义变量，并让管理页、统计页、闪卡页及侧栏卡片共用同一组颜色。Native 跟随 Obsidian 的主题变量和 `--interactive-accent`，其余主题保留各自配色。

现有舒适/温馨/紧凑密度、自动或 1–4 列及自定义强调色继续生效。外观升级不改变这些设置的存储或含义。样本左侧导航是效果展示；正式落地以当前 Studio 视图和插件整体外壳为准，不强行加入第二套导航。

## 方案 B：典型闪卡与复习机制

复习区域已改成中央单卡、单面展示。正面只显示摘录，下面提示先回想自己的笔记；点击卡片或按空格/回车后，原位翻到背面，显示完整笔记、图片和来源。背面下方出现四个评分按钮，旁边显示根据当前 FSRS 状态计算的下次间隔。正反面不会同时出现。

顶部显示“今天到期 X · 新卡 Y”和本次进度；底部保留跳转原文、跳过、退出。桌面支持空格/回车翻面、数字 1–4 评分；移动端保留清晰的大按钮与触摸区域。评分后立即持久化现有 FSRS 状态，再进入下一张。未翻面不能评分。

复习队列按最早到期顺序加载到期卡，新卡受现有每日上限控制；学习中的卡进入等待队列，到 FSRS 计划时间到达后才重新出现。当前队列结束时显示复习摘要和最早下次时间。跳过只移动当前卡，不写入评分。结束页显示复习数量和四级评分分布，并提供下一轮入口。
