桌面书架顶栏设计稿

针对「顶部两行菜单不统一」的两个重设计方案：方案 A 把两行统一成编辑部报头式的「刊头 + 安静控件」，延续手机端选定的文字导航语言；方案 B 把两行装进同样的圆角横带，靠重复容器求统一。窗口里的页签和按钮可以点按，右上角切换深浅色。

现状（桌面 · 书籍页）

第一行是透明底、无边框的胶囊页签和圆角按钮；第二行一下子换成清一色带边框的下拉、输入框和图标，还压一条底部分隔线。两行的高度（52 / 46）、圆角（999 / 7）、底色（透明 / 灰面）三套语言并存，视觉重心互相打架，这是「不统一」的根源。

方案 A · 编辑部报头（推荐）

整页当作一本刊物的首页：第一行是刊头——衬线体 HiLighter 加小字「书架」，页签变成纯文字加短下划线（和手机端同一种语言，桌面去掉图标），右侧只剩「卡片集」文字按钮和一个无框齿轮，刊头下一根细分割线。第二行全部换成「幽灵控件」：下拉只剩文字和小箭头、搜索是一条下划线输入、图标全部无框，统一 40px 行高。两行共用一套颜色（灰字-黑字-主题色）和一个高度节奏（56 / 44），控件再多是同一张面孔。

方案 B · 双横带（保守）

控件语言保持现状（边框下拉、边框按钮、胶囊页签），但把两行分别装进同样的圆角横带里：同一个底色、同一条边框、同一个 12px 圆角、同一套 34px 控件高度，靠「容器重复」达成统一。改动几乎只在 CSS，风险最小；代价是比现在更「工具栏软件」，与 editorial 主题的纸感气质不贴。

保留现有控件容器统一改动最小

两个方案共同的原则

  • 一个高度节奏：第一行刊头/横带 56px，第二行控件 44px，行内所有控件同一高度，不再出现 30 / 34 / 46 混排。
  • 一套颜色语言：灰字 = 未选中，黑字 = 悬停/当前值，主题色只给「选中的页签 / 激活的筛选」，一个页面同时只有一处主题色高亮。
  • 近期阅读页自动受益：它的第二行只有排序 + 格式两个下拉，换成同一套控件语言后两行关系立刻一致。
  • 平板：沿用同一设计，窄宽度时第二行控件照旧折行成两层（现有行为），视觉语言不变。

实施要点

  • 方案 A：view.ts 页签去图标改纯文字（下划线选中）；styles.css 重写顶栏与工具栏控件皮肤——下拉改 appearance:none 的幽灵样式（文字+箭头）、搜索改下划线输入、图标按钮去边框、去掉工具栏底部分隔线；品牌行改衬线体。逻辑零改动，全是皮肤。
  • 方案 B：只动 styles.css：顶栏与工具栏各包一层横带容器样式（或给现有容器加底色/边框/圆角），统一控件高度与圆角。
  • 两个方案都不改任何交互逻辑（下拉、菜单、多选、分页全部保持）。

怎么定

看完设计稿回复 A 或 B；要调细节（衬线品牌是否保留、页签要不要留图标、下划线搜索的宽度、横带圆角大小等）直接说，改完稿再确认，通过后才动代码。
